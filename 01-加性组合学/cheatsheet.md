# 速查表

## 记号

| 记号 | 含义 |
|---|---|
| A+B | {a+b : a∈A, b∈B} |
| A−B | {a−b : a∈A, b∈B} |
| kA | A+A+…+A（k 次） |
| σ[A] | \|A+A\|/\|A\| |
| E(A,B) | 满足 a+b=a'+b' 的四元组个数 |
| Â(ξ) | Σ_{a∈A} ξ(a)，傅立叶系数 |
| d(A,B) | log(\|A−B\|/√(\|A\|\|B\|)) |
| U^k | Gowers k 阶范数 |
| I(P,L) | 点集 P 与线集 L 的关联数 |

## 核心不等式

| 名称 | 内容 | 用在哪 |
|---|---|---|
| 平凡下界 | \|A+B\| ≥ \|A\|+\|B\|−1（ℤ 中） | 一维估计 |
| 柯西-能量 | E(A,B) ≥ \|A\|²\|B\|²/\|A+B\| | 能量与和集互推 |
| Ruzsa 三角 | d(A,C) ≤ d(A,B)+d(B,C) | 距离传递 |
| Ruzsa 覆盖 | \|A+B\|≤K\|B\| ⟹ A ⊂ A'+B−B，\|A'\|≤K | 局部化 |
| Plünnecke | \|A+B\|≤K\|B\| ⟹ \|kA+lB\|≤K^{k+l}\|B\| | 多次和集 |
| Brunn–Minkowski | \|A+B\|^{1/d} ≥ \|A\|^{1/d}+\|B\|^{1/d} | 凸体体积 |
| Parseval | Σ\|f\|²=(1/\|Z\|)Σ\|f̂\|² | 能量守恒 |
| 能量-傅立叶 | E(A,A)=Σ\|Â(ξ)\|⁴ | 谱估计 |
| Esséen | sup P(Σεv=x) ≤ C/√(Σ\|v\|²) | 集中度 |
| Turán | 独立集 ≥ n²/(2e+n) | 无和集 |
| 交叉数 | 交叉 ≥ m−3n+6（n≥3） | 关联几何 |
| S-T | I(P,L) ≲ \|P\|^{2/3}\|L\|^{2/3}+\|P\|+\|L\| | 点线关联 |

## 常数与界

| 量 | 值或量级 | 备注 |
|---|---|---|
| 最大无和子集（[1,n]） | ⌈n/3⌉ | 奇数构造可达 |
| 秩 d 长度 N 的 GAP 体积 | (N+1)^d | 真时等于元素数 |
| 小倍增精确刻画阈值 | σ<2 或 σ<3 | 视群结构而定 |
| LO 集中度（步长全 1） | ~2^d/√d | 二项式系数峰值 |
| 随机 Bernoulli 矩阵奇异率 | (1/2+o(1))^n | 逆 LO 证明 |
| Szemerédi k=3 定量界 | log log N 起，改进到 (log N)^c | 逐步优化 |

| 要证什么 | 首选工具 | 备选 |

## 三个最常搞混的点

- **和集小 ≠ 集合是等差数列**：也可能是子群、陪集、低秩 GAP。
- **偏差大 ≠ 有等差数列**：只说明偏向某频率，形状可能复杂。
- **能量大 ≠ 整个集合规整**：只保证存在大子集规整。
