# Bohr 集

- **难度**：高难 | **涉及章节**：第 4、10 章

## 一句话定义

B(Δ,ρ) = {x : 对所有 ξ∈Δ，|ξ(x)−1| ≤ ρ}，是若干频率上同时接近 1 的元素的集合。

## 为什么重要

它是"多频率偏差"对应的几何结构，也是密度增量论证里"密度变高的那个子结构"。

## 图示

```mermaid
graph LR
    A[频率集合] --> B[Bohr集]
    B --> C[子群或低维GAP]
    C --> D[密度增量]
```

## 详解

在循环群里，Bohr 集可以看成"多条同余条件的交集"。它的"维数"由频率集合的大小决定，体积由半径 ρ 和频率结构共同决定。

## 常见误解

别以为 Bohr 集一定等于 GAP。两者在特定条件下对应，一般只是"低复杂度的子群"。
