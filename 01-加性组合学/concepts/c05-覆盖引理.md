# 覆盖引理

- **难度**：进阶 | **涉及章节**：第 2、5 章

## 一句话定义

若 |A+B| ≤ K|B|，则存在 A' ⊂ A，|A'| ≤ K，使 A 被 A'+B−B 覆盖（Ruzsa 版本）。

## 为什么重要

它把"整个集合"的问题降成"骨架"的问题，是几乎所有结构证明的第一步。

## 图示

```mermaid
graph LR
    A[和集小] --> B[骨架A']
    B --> C[平移覆盖]
    C --> D[局部化]
```

## 详解

覆盖不是相等：A 可能比骨架大得多，只是每个元素都能写成 a'+b−b' 的形式。这样后续只需控制骨架，代价是引入差集。

## 常见误解

别以为骨架就是 A 的结构。骨架可能仍然很复杂，覆盖只是给了个"坐标系统"。
