# 组合零点定理

- **难度**：高难 | **涉及章节**：第 9 章

## 一句话定义

若多项式次数不超过 Σt_i，且最高次项系数非零，则在足够大的格点集 S₁×...×S_n 上必存在非零点。

## 为什么重要

它把"存在某个组合"变成"多项式系数不为零"，是有限域上加性问题的标准武器。

## 图示

```mermaid
graph LR
    A[多项式] --> B[最高次项系数]
    B --> C[格点非零]
    C --> D[受限和集下界]
```

## 详解

条件 |S_i|>t_i 保证格点数量超过次数上界；系数非零保证多项式不能在格点上"假装为零"。去掉任一条件定理都不成立。

## 常见误解

别以为它对整环成立。需要域，"零点数 ≤ 次数"才可靠。
