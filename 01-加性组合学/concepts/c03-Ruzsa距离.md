# Ruzsa 距离

- **难度**：进阶 | **涉及章节**：第 2 章

## 一句话定义

d(A,B) = log( |A−B| / √(|A||B|) )，是加性集之间的一个度量。

## 为什么重要

它把"和集小"转成"两个集合在度量意义下很近"，于是可以用三角不等式在多个集合之间传递信息。

## 图示

```mermaid
graph LR
    A[A与B接近] --> B[差集小]
    B --> C[三角不等式]
    C --> D[传递结构]
```

## 详解

选差集而不是和集，是因为差集有对称性，且 A−A 总包含 0，度量性质更好证。d=0 只说明 |A−B| 达到 √(|A||B|)，不说明两个集合相等。

## 常见误解

别把它当普通距离。它是对数尺度，且只反映大小，不反映元素位置。
